## 🔒 Security & QA Hardening

This codebase was submitted to an end-to-end defensive audit modeled after the **OWASP Top 10** guidelines:

- 🛡️ **Zero Vulnerabilities**: Clean `npm audit` report with 0 high, moderate, or low security alerts.
- 🚫 **XSS & Injection Immune**: Zero `dangerouslySetInnerHTML`, zero `eval()`, and zero execution of dynamic runtime strings.
- 🔗 **Tabnabbing Defense**: All external hyperlinks strictly enforce `rel="noopener noreferrer"`.
- 🔍 **SEO & Crawler Verified**: Automated `public/robots.txt` and `public/sitemap.xml` with rich JSON-LD Schema markup.
- ⚡ **Optimized Gzip Profile**: Production client JavaScript under `185 KB` (gzipped), total stylesheets under `12 KB` (gzipped).

## ⚡ Quickstart & Local Installation

Clone the repository and spin up the development container in under 60 seconds:

```bash
# 1. Clone the repository
git clone https://github.com/garvshaw89-glitch/portfolio.git

# 2. Navigate to project root
cd portfolio

# 3. Install dependencies
npm install

# 4. Launch local development server (binds to http://localhost:3000)
npm run dev
```

### Production Build & Verification

```bash
# Run strict TypeScript type verification
npm run lint

# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
